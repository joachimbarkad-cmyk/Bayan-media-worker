# Rapports de revue Codex

Un fichier par revue : `<date>-<lot>-<sha12>.json` (rapport complet validé) et `.md` (résumé lisible). Produits uniquement par `scripts/request_codex_review.py` (voir `docs/PROTOCOL.md`). Un rapport `BLOCKED` n'est jamais une approbation. `pending/` contient les dossiers préparés quand Codex n'est pas exécutable.
